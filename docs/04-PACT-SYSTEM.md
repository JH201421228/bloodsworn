# 04. THE PACT — 핵심 시스템 명세

> **문서 지위: 정본(CANON).** 이 게임의 유일한 차별화 지점. 다른 모든 것을 잘라도 이건 남긴다.
> 데이터 포맷은 `08-DATA-SCHEMA.md`, 구현은 `06-TECH-DESIGN.md` §PactSystem 참조.

## 1. 시스템 요약

레벨업 → **계약서 3장** 제시 → 1장 선택 → **축복 1개 획득 + 대가 1개 부과**

```
┌───────────────── 계 약 서 ─────────────────┐
│  ✦ 축복                                     │
│    화염탄  Lv.2  →  Lv.3                    │
│    투사체 +1                                │
│ ─────────────────────────────────────────── │
│  ✖ 대가                            [ 근시 ] │
│    모든 무기 사거리 -18%                    │
│    (근시 중첩: ●●○  →  3중첩 시 각성)       │
│ ─────────────────────────────────────────── │
│  인간성 -6                                  │
└─────────────────────────────────────────────┘
```

## 2. 왜 이게 재미있는가 (설계 근거)

| 기존 뱀서류 | BLOODSWORN |
|---|---|
| 레벨업 = 무조건 이득 → 선택이 "최적해 찾기" | 레벨업 = 손익 계산 → 선택이 **딜레마** |
| 강한 카드를 뽑으면 그냥 좋음 | 강한 카드일수록 **대가가 무겁다** (등급 연동) |
| 빌드 = 어떤 무기를 모았는가 | 빌드 = **어떤 저주를 감당하기로 했는가** |
| 저주/디버프는 순수 페널티 | 저주 3중첩 = **각성**으로 최강 능력 전환 |

**핵심 심리:** 플레이어는 "손해를 피하려" 하다가, 어느 순간 **"손해를 일부러 모으기"** 시작한다.
그 전환점이 이 게임의 아하 모먼트다.

## 3. 등급 & 대가 강도 연동

축복은 3등급. **축복 등급이 높을수록 대가가 무겁다.**

| 등급 | 색 | 출현 가중치 | 축복 강도 | 대가 강도 | 인간성 감소 |
|---|---|---|---|---|---|
| **Common** | 회백 | 60 | 소 | 소 (1중첩) | −3 |
| **Rare** | 청록 | 30 | 중 | 중 (1중첩, 수치 1.8배) | −6 |
| **Epic** | 심홍 | 10 | 대 | 대 (**2중첩** 부여) | −12 |

> **Epic이 2중첩을 주는 것이 핵심 설계.** Epic 2장이면 즉시 각성(3중첩 도달 가능).
> "강한 걸 두 번 집으면 각성이 터진다" — 이 리듬이 6분 런에 각성 2회를 안정적으로 만든다.

### 3.1 등급 가중치 보정
- 레벨이 오를수록 상위 등급 확률 증가: `rareW = 30 + level×1.2`, `epicW = 10 + level×0.8`
- **Lv 20 실제 계산값: Common 42.9% / Rare 38.6% / Epic 18.6%** (초안의 40/38/22는 오차)
- Epic을 22%까지 올리고 싶다면 `epicW = 10 + level×1.2`로 상향한다. 단 각성 속도가 빨라지므로
  §5.4 각성 상한(2개)에 조기 도달한다는 점을 감안할 것.

## 4. 대가 계열 (Toll Tags) — **6종**

각 대가는 정확히 하나의 **태그**를 가진다. 태그가 각성의 단위다.

| # | 태그 | 한글명 | 저주 효과 (1중첩당, Common 기준) | 플레이 체감 |
|---|---|---|---|---|
| T1 | `FRAIL` | **허약** | maxHp −12% | 스치면 죽는다 |
| T2 | `SLOW` | **둔족** | moveSpeed −10% | 도망칠 수 없다 |
| T3 | `MYOPIA` | **근시** | 무기 사거리 −18% | 붙어야 한다 |
| T4 | `GREED` | **탐욕** | expMult −15% | 레벨이 안 오른다 |
| T5 | `BLIND` | **암야** | 시야 반경 −22% (비네트) | 안 보인다 |
| T6 | `HUNGER` | **갈증** | 초당 HP −0.8 (자연 감소) | 계속 사냥해야 한다 |

**중첩 시 수치 계산 (곱연산 누적, 하한 존재)**
```
FRAIL:  maxHp   ×= (1 - 0.12 × 등급배율)   하한 maxHp 25
SLOW:   speed   ×= (1 - 0.10 × 등급배율)   하한 speed 32 px/s
MYOPIA: range   ×= (1 - 0.18 × 등급배율)   하한 range ×0.35
GREED:  expMult ×= (1 - 0.15 × 등급배율)   하한 expMult 0.40
BLIND:  vision  ×= (1 - 0.22 × 등급배율)   하한 vision 90 px
HUNGER: drain   += 0.8 × 등급배율          상한 drain 4.0/s
```
등급배율: Common 1.0 / Rare 1.8 / Epic 1.4 (**Epic은 수치는 낮되 2중첩**)

> **하한(floor)은 필수 안전장치다.** 없으면 SLOW 5중첩에서 게임이 물리적으로 진행 불가능해진다.

## 5. ★ 각성 (Awakening) — 시스템의 심장

### 5.1 발동 조건
**같은 태그 3중첩 도달 즉시** 발동. 자동. 플레이어 선택 없음.
(성소 「각성 촉진」 업그레이드로 3 → 2.6까지 완화 가능)

### 5.2 발동 연출 (반드시 강렬해야 함)
1. 게임 정지 (0.2초 히트스톱)
2. 화면 전체 심홍 플래시 → 흑백 반전 0.15초
3. 중앙에 각성 이름 대형 타이포 + 인장 아이콘
4. 사운드: 낮은 종소리 + 심장박동 스팅
5. 플레이어 주변 원형 충격파 → **화면 내 모든 적 넉백 + 2초 스턴**
6. 이후 플레이어에 상시 파티클 오라 부착 (태그별 색상)

> 이 연출에 하루의 1/4를 써도 아깝지 않다. **이게 게임의 대표 스크린샷이 된다.**

## 6. 카드 생성 알고리즘

```
generatePactCards(playerState) -> Card[3]

1. 등급 롤 (3장 각각 독립)
   rarity = weightedPick({common: 60, rare: 30 + lv*1.2, epic: 10 + lv*0.8})

2. 축복 후보 필터
   - 무기 슬롯 5개 꽉 참 → 신규 무기 제외, 보유 무기 강화만
   - 이미 Lv5(MAX)인 항목 제외
   - 후보 0개면 → 폴백 축복 "피의 결정"(HP 30 회복 + damage +3%) 제공
   
3. 대가 롤
   - 태그 풀에서 가중치 랜덤. 단:
     · 이미 각성한 태그는 **가중치 0** (중복 각성 방지)
     · 각성 상한(2개) 도달 시 → **이 카드가 3중첩을 찍게 만드는** 태그는 후보에서 제외
       (2중첩 여부가 아니라 "현재 중첩 + 이 카드의 중첩 >= 3" 으로 판정한다.
        Epic 은 +2중첩이라 1중첩 태그도 한 번에 3을 찍는다)
       — 단 **마지막 3번째 장에만** 남겨 두고 가중치 ×0.2 (§6.3)
     · 하한(floor)에 도달한 태그는 가중치 ×0.3 (무의미한 대가 방지)
     · 후보가 **완전히 비면** → 폴백: 이미 각성한 태그를 더 깊게 판다 (§6.3)
   - Epic이면 동일 태그 2중첩 부여

4. 중복 방지
   - 3장의 (축복 id)가 서로 달라야 함
   - 3장의 (대가 태그)는 최소 2종류 이상이어야 함

5. "각성 임박" 하이라이트
   - 선택 시 3중첩이 완성되는 카드는 카드 테두리가 **맥동하는 금빛**
   - 문구: "이 계약으로 각성한다"
```

### 6.1 리롤
- 런당 **2회** (성소 「재계약」으로 최대 5회)
- 3장 전체 재생성. 리롤 버튼은 카드 하단 중앙.
- **대가만 리롤은 제공하지 않는다** (딜레마가 사라짐)

### 6.2 스킵
- 카드 3장을 모두 거절 가능. 보상: **HP 25% 회복 + 골드 +30**
- 인간성 감소 없음. **후반 인간성 관리의 유일한 수단.**

### ★ 6.3 대가 고갈과 폴백 (2026-08-12 수정)

각성 상한(2)에 도달하면 §6 단계 3 의 규칙 두 개가 동시에 걸린다 — 각성한 2태그는 **영구 제외**,
남은 4태그도 3중첩을 찍는 순간 제외. 남은 4태그가 전부 2중첩에 닿으면 **후보가 0개**가 된다.
그러면 그 카드는 **대가가 없다.** 여기까지는 의도된 설계다("녹턴이 그 방향으로는 더 가져갈 게 없다").

문제는 그 상태가 **후반의 기본값**이었다는 것이다.

| Lv | 대가 없는 카드 (폴백 전) |
|---|---|
| ~12 | 0.1 % |
| 16 | 21.3 % |
| 20 | 53.7 % |
| 30 | **66.2 %** |

> 800~4000런 시뮬(무작위 선택 정책 · Lv2~30). 대가 없는 축복이 후반의 2/3 이면 그것은 PACT 가 아니다.

**폴백 규칙** — 후보 풀이 **완전히 비었을 때만**, **이미 각성한 태그**를 다시 후보로 쓴다.
두 조건을 **모두** 만족해야 한다.

| 조건 | 이유 |
|---|---|
| `awakenings.json` 의 `removePenalty === false` | 각성 후에도 **스탯 페널티가 남는** 태그. 더 쌓으면 실제로 더 아프다. `true` 인 태그는 각성이 모디파이어를 걷어냈으므로 다시 쌓아도 안 아프다 — 이름만 대가인 공짜 축복이라 폴백에서도 뺀다 |
| 하한(floor)·상한(cap)에 닿지 않았다 | 닿은 뒤에는 수치가 변하지 않아 역시 가짜 비용이다. **셋 다 포화면 여전히 대가 없음이 맞다** — 그때는 진짜로 가져갈 게 없다 |

현재 데이터 기준 폴백 후보는 **「허약」FRAIL · 「갈증」HUNGER · 「암야」BLIND** 셋이다
(`removePenalty: false`). 「둔족」SLOW · 「근시」MYOPIA · 「탐욕」GREED 는 `true` 라 제외된다.

**상한이 깨지지 않는 이유** — `AwakeningSystem.trigger` 가 첫 줄에서 `has(tag)` 로 막는다.
같은 태그는 두 번 각성하지 않으므로 §5.4 의 "3번째 태그 → 인간성 −20" 검사에 **아예 닿지 않는다.**
카드 쪽도 마찬가지다 — 중첩이 이미 3 이상이라 "각성 임박" 하이라이트가 서지 않는다.

| 지표 | 무작위 (전 → 후) | 고등급 우선 (전 → 후) |
|---|---|---|
| 대가 없는 카드 Lv14 | 4.1 % → **0.8 %** | 16.6 % → **6.2 %** |
| 〃 Lv16 | 21.3 % → **6.4 %** | 39.5 % → **23.9 %** |
| 〃 Lv18 | 42.0 % → **21.6 %** | 55.6 % → **45.5 %** |
| 〃 Lv20 | 53.7 % → **38.5 %** | 62.8 % → **57.8 %** |
| 〃 Lv30 | 66.2 % → 62.8 % | 66.7 % → 65.9 % |
| 〃 Lv4+ 전체 | 31.4 % → **25.4 %** | 36.4 % → **32.8 %** |
| 인간성 −20 초과 / 런 | 3.08 → **3.07** (안 늘었다) | 2.27 → **2.25** (안 늘었다) |
| 각성 태그 재제시 / 런 | 0.00 → **0.00** | 0.00 → **0.00** |
| 인간성 0 도달률 | 96.4 % → 98.8 % | 95.8 % → 97.6 % |

#### ⚠ 6.3.1 남아 있는 것 — 폴백으로는 후반을 못 고친다

Lv20 이후로 효과가 급격히 줄어드는 데는 **구조적 이유 두 가지**가 있다. 폴백을 어떻게 튜닝해도
여기서 더 못 내려간다.

1. **폴백 후보 수가 카드 수보다 적다.** 각성은 런당 2개이고 그중 `removePenalty:false` 인 것은
   평균 **0.98개**(6태그 중 3개가 해당 → 2 × 0.5). 카드 3장은 서로 다른 태그를 써야 하므로
   후보가 1개면 **3장 중 1장만** 대가를 받는다 → 이론적 하한이 33 %다.
2. **「완전 흡혈귀화」가 폴백 후보를 포화시킨다.** §5.4 의 "모든 대가 페널티 2배"가 걸리면
   BLIND(시야 하한 90)와 HUNGER(드레인 상한 4.0/초)는 **즉시** 상한에 닿는다. Lv30 시점에
   살아 있는 폴백 후보는 런당 **0.10개**뿐이다(600런 계측).

즉 후반의 「대가 없는 카드」는 대가 추첨의 문제가 아니라 **인간성 예산의 문제**다.
인간성 100 에 카드당 평균 비용이 4.8(=0.6×3 + 0.3×6 + 0.1×12)이면 **약 21장**에서 0 이 된다.
Lv4~30 은 27장이므로 인간성 0 은 사실상 **산술적으로 예정돼 있다** —
실측 인간성 0 도달률 96~99 %, 중앙 도달 시점 **Lv20 전후**.
§5.4 가 「완전 흡혈귀화」를 "도전 과제"로 정의한 것과 어긋난다.
**고치려면 인간성 예산(비용표 · 상한 초과 −20 · 스킵 보상) 쪽을 손대야 한다.** 별건이다.

## 8. 인간성(Humanity) 시스템

| 항목 | 값 |
|---|---|
| 초기값 | 100 |
| 감소 | Common −3 / Rare −6 / Epic −12 / 각성 상한 초과 −20 |
| 회복 | 스킵 선택 시 없음. **회복 수단 없음** (단방향) |
| 0 도달 | 「완전 흡혈귀화」 발동 (§5.4) |
| UI | 상단 좌측 심장 아이콘 5개. 20%마다 1개씩 검게 변함 |

**예상 소모 (검산 반영):** 안전장치 S4로 Lv1~3은 대가가 없으므로 대가 카드는 **16장**.
16 × 평균 −5.47 = **−87.5**, 각성 상한 초과 페널티 −10을 더해 **총 −97.5**.
→ 런 종료 시 인간성 기대값 **약 2.5**. 대부분의 런에서 인간성 0에 근접한다.

이는 **의도된 설계**다. 스킵을 쓰거나 Common을 골라 인간성을 아끼는 것이 엔딩 A의 조건.
