⚠ 확인 필요(2026-08-10 기준 미확인) — GitHub Actions 무료 분수는 3자 출처다. 채택을 뒤집을 때는 GitHub 공식 청구 문서로 재확인할 것.

### ★ iOS 관통 1단계 (1.5h) — 블록 A/B/C 사이의 대기·잡무 시간에 분산

> **게임 개발 블록의 시간을 쓰지 않는다.** CI 빌드 1회가 10분 안팎이고 그동안 손이 비므로,

| 순서 | 작업 | 비고 |
|---|---|---|
| 1 | `npx cap add ios` → `ios/` 생성 후 **커밋 + 원격 푸시** | Windows에서도 **생성 자체는 된다.** macOS가 필요한 건 빌드뿐이다 |

| 3 | Codemagic 워크플로 작성 — `npm ci` → `npm run build` → `cap sync ios` → **`pod install`** → `xcodebuild archive` → `exportArchive` | **CocoaPods 단계가 빠지면 반드시 실패한다** |

| 5 | **첫 그린 빌드 = `.ipa` 산출**까지 반복 | 실패 로그가 유일한 진단 수단이다 |

> ⚠️ **여기는 25분 룰(§0.1-2)의 예외다.** 우회 경로가 없고 왕복이 원래 길다. 대신 **Day 1+Day 2 누적 3h를 상한**으로 두고,

> ⚠ 확인 필요(2026-08-10 기준 미확인) — `xcodebuild`/`exportArchive`의 정확한 최신 플래그 조합. 위 표는 **단계 골격**이며 실제 명령은 `14-BUILD-AND-DEPLOY.md` §6.4에서 확정한다.

> iOS는 게임 내용이 아니므로 위 6단계 어디에도 넣지 않는다. 대신 **Day 2 종료 게이트에서 단독으로 판정**한다(§4).
> 게이트를 통과하지 못하면 아래 목록을 건드리기 전에 **iOS를 먼저 뺀다** — 게임을 깎아 배포 채널을 사는 거래는 하지 않는다.
