## 30초 요약

**"모든 축복에는 대가가 따른다. 대가를 끝까지 견디면, 대가가 곧 힘이 된다."**

6분 안에 새벽까지 살아남는 서바이버즈. 레벨업할 때마다 **축복(Blessing)** 과 **대가(Toll)** 를
한 쌍으로 받는다. 같은 계열의 대가가 3번 쌓이면 **각성(Awakening)** 이 발동해 그 저주가
정반대의 강력한 능력으로 뒤집힌다. **빌드 = 어떤 저주를 감당하기로 했는가.**

## 🚀 읽는 순서

**목적에 따라 경로가 다르다.** 전부 읽으려 하지 말 것 — 합계 1.4MB 다.

### A. 처음 합류했다 / 이 게임이 뭔지 알아야 한다 (약 80분)

```
1️⃣  01 컨셉  →  04 PACT              (30분)  "무엇을 만드는가"
2️⃣  03 GDD                           (20분)  "어떻게 굴러가는가"
3️⃣  26 스테이지·보스                  (20분)  "지금 실제로 무엇이 들어 있는가"
4️⃣  16 리스크 §0·§5·§9               (10분)  "무엇을 자를 준비를 하는가 / 무엇이 결정 대기인가"
```

⚠ **3번을 `03 GDD` 앞에 두지 않는 것이 중요하다.** `26` 은 실태 기록이라
**의도를 모르는 채 읽으면 "왜 이렇게 됐는지"를 판단할 수 없다.**

### B. 오늘 코드를 짠다 (약 50분)

```
06 기술 → 07 구조 → 08 데이터 스키마 → 12 백로그
```
⚠ **수치는 문서가 아니라 `FE/src/data/*.json` 이 진실이다.** 문서는 "의도", JSON 은 "현재값".
**둘이 다르면 `26` 문서 §8 의 12건 중 하나일 가능성이 높다.**

### C. 출시·수익화·규제를 다룬다 (약 60분) ← **지금 국면에서 가장 중요한 경로**

```
1️⃣  27 컴플라이언스  ★ 여기부터. 마감이 들어 있다   (20분)
2️⃣  16 리스크 §1·§2                                (15분)
3️⃣  17 라이선스 §0                                 (10분)
4️⃣  25 성장·UA  →  21 라이브옵스                    (15분)
```

### D. 밸런싱을 만진다

```
05 전투·밸런스 §5·§6  →  26 스테이지·보스 §3·§5  →  16 리스크 §6
```
⚠ **§6 을 반드시 마지막에 읽을 것.** 현재 밸런싱 값의 상당수가 **플레이테스트를 거치지 않았다.**
어떤 값을 신뢰할 수 있고 어떤 값이 추정인지 모르면 튜닝이 아니라 도박이 된다.

## 🎯 절대 방어선

### 게임으로서 (Minimum Shippable Game)
- ✅ 가로 화면에서 조이스틱으로 움직인다
- ✅ 적이 몰려오고 무기가 자동으로 나간다
- ✅ 레벨업 시 **PACT 카드 3장** — 축복 + 대가
- ✅ **각성 최소 1종**이 실제로 터진다
- ✅ 죽으면 결과 화면 → 3초 안에 재시작

### 프로젝트로서 (`16` §5.3 P0 — 컷 대상이 아니다)
- 🔴 **분석 계측** — 없으면 소프트런치가 그냥 조용한 출시가 된다
- 🔴 **소프트런치 자체** — 6개월의 목표는 "출시"가 아니라 **"D1·D7·ARPU÷CPI 를 실측으로 아는 것"**
- 🔴 **라이선스 청산** — 수익화 앱에 회색은 없다
- 🔴 **PACT · 각성 · 6분 런** — 이게 없으면 다른 서바이버즈와 구별되지 않는다

컷 순서 전문: [16. 리스크 & 스코프 컷 라인](./16-RISKS-AND-SCOPE-CUTS.md) §5

## 📌 문서 관리 규칙

1. **정본(01/03/04)을 고치지 않고 다른 문서만 고치지 않는다.** 설계 변경은 정본부터.
2. **수치는 문서가 아니라 `FE/src/data/*.json` 이 진실이다.** 문서는 "의도"를, JSON 은 "현재값"을 담는다.
3. ★ **의도를 완료형으로 쓰지 않는다.** `_note` / `_designNote` 에 "이렇게 동작한다"고 쓰면
   **6개월 뒤의 자신이 그걸 사실로 읽는다.** 미구현은 미구현이라고 적는다. (`26` 문서 §8 이 이 규칙이 생긴 이유다)
4. **확인하지 못한 것은 "확인하지 못했다"고 쓰고, 추정은 추정이라고 밝힌다.** (`27` 문서 §11 이 모범)
5. 표기 규칙: **한자를 쓰지 않는다.** 폰트에 한자 글리프가 없어 두부(□)가 된다.
6. 문서 번호는 재사용하지 않는다. 결번(24)을 메우지 말 것.
