## 30초 요약

**"모든 축복에는 대가가 따른다. 대가를 끝까지 견디면, 대가가 곧 힘이 된다."**

6분 안에 새벽까지 살아남는 서바이버즈. 레벨업할 때마다 **축복(Blessing)** 과 **대가(Toll)** 를
한 쌍으로 받는다. 같은 계열의 대가가 3번 쌓이면 **각성(Awakening)** 이 발동해 그 저주가
정반대의 강력한 능력으로 뒤집힌다. **빌드 = 어떤 저주를 감당하기로 했는가.**

| 항목 | 값 |
|---|---|
| 화면 | 가로(Landscape) 고정 · 논리 해상도 **640×360** |
| 1 런 | **6분** (90초마다 페이즈, 6:00에 보스) |
| 조작 | 좌: 플로팅 조이스틱 / 우: 대시 · **공격 전자동** |
| 스택 | React 19 + Vite 7 + Phaser 3.90 + Zustand 5 + Capacitor 7 + Tiled |
| 배포 | **Android + iOS 동시.** Day 7에 **Play 내부 테스트(AAB)** + **TestFlight 내부 테스트(IPA)** 동시 업로드 |
| 빌드 환경 | Windows · **Mac 없음** → iOS는 **클라우드 macOS CI(Codemagic)** 로 빌드. Apple Developer Program 가입 완료 |

> **배포 채널 변경 (2026-08-10 확정):** itch.io 웹 배포는 **전면 제외**되었고 iOS가 추가되었다.
> 배포 경로는 여전히 2개지만 성격이 다르다 — itch.io는 마찰 0이었고 TestFlight은 계정·서명·CI에 의존한다.

## 🧱 현재 코드베이스 상태 (Day 1 시작 전 확인 사항)

`FE/`에 Vite + React 19 + Phaser 3.90 + Zustand 5 + Capacitor 7 스캐폴드가 이미 존재한다. 다만:

**결론: 이건 "동작하는 스캐폴드"가 아니라 이전 프로젝트의 미완성 잔재다.**
Day 1 오전을 통째로 정리에 쓰되, **2시간을 넘기면 폐기하고 새로 만드는 편이 빠르다.**

| 문제 | 상태 | 조치 |
|---|---|---|
| `game/GameManager.js`가 존재하지 않는 `./scenes/AudienceRoomScene.js`를 import (`scenes/` 디렉토리 자체가 없음) | 🔴 **빌드 불가** | T106 |
| `game/config.js`가 세로 375×667 + `Scale.RESIZE` + 이전 프로젝트 잔재(`AUDIENCE_LAYOUT`) | 🔴 전면 교체 | T104, T105 |
| **`router/index.jsx`가 `App`을 레이아웃으로 쓰는데 `<Outlet/>`이 없음** → 자식 라우트가 렌더된 적 없음 | 🔴 삭제 | T103 |
| **`MainPage.jsx` 본문이 `return;`** (undefined 반환 → React 19 렌더 에러), `MainPage.module.css`는 0바이트 | 🔴 삭제 | T103 |
| **`src/.env`가 0바이트 + `src/` 아래는 Vite가 읽지 않는 위치**. `getEnv()`는 미정의 시 throw | 🔴 삭제 | T103b |
| `App.jsx`가 Vite 기본 템플릿 그대로 | 🟠 교체 | T102 |
| 미사용 의존성 5개 (`firebase`/`axios`/`react-query`/`react-hook-form`/`react-router-dom`, gzip 약 176KB) | 🟠 제거 | T101 |
| **`AndroidManifest.xml`에 `android:screenOrientation` 속성 자체가 없음** | 🔴 가로 고정 미충족 | T705 |
| `index.html` — `lang="en"`, `<title>fe</title>`, `viewport-fit=cover`·`user-scalable=no` 누락 | 🟠 수정 | T103d |
| `index.css`의 `font-weight: 100 900 /* Variable font */`는 사실과 다름(fvar 없음) + `antialiased`는 픽셀 폰트에 정반대 | 🟠 수정 | T127 |
| `appId: com.superdimension.app`, `appName: SuperDimension` | 🟠 변경 | T701~ |
| `targetSdk 35` | 🔴 **2026-08-31부터 36 필수** | T103e |
| **git 저장소 아님** + OneDrive 동기화 폴더 안 | 🔴 **iOS 최상위 블로커로 격상** | D0-4, D0-4b |

> ⚠️ **firebase 제거는 라이선스가 아니라 정책 문제이기도 하다.** 이게 남아 있으면 Play Console

## 🎯 절대 방어선 (Minimum Shippable Game)

일정이 무너져도 **이것만은 남긴다.** 이게 없으면 이 프로젝트는 존재 의미가 없다.

- ✅ 가로 화면에서 조이스틱으로 움직인다
- ✅ 적이 몰려오고 무기가 자동으로 나간다 (**W1 「피의 송곳니」 + W2 「화염탄」**)
- ✅ 레벨업 시 **PACT 카드 3장** — 축복 + 대가
- ✅ **각성 최소 1종**이 실제로 터진다
- ✅ 죽으면 결과 화면 → 3초 안에 재시작

## 🚫 프로덕션 출시는 이번 주 목표가 아니다

**양 스토어 모두 "테스트 배포"까지가 이번 주 목표다.** 정식 공개는 구조적으로 불가능하다.

- **Android** — 2023-11-13 이후 개설된 **개인** 개발자 계정은 프로덕션 접근 신청 전에
  **테스터 12명 × 14일 연속 옵트인** 폐쇄형 테스트가 필수이고, 신청 후 심사에 최대 7일이 더 걸린다.
  최단 경로도 **21일 이상**이다. 내부 테스트 트랙은 이 요건의 대상이 **아니므로** Day 7 목표는 유효하다.
- **iOS** — App Store 정식 제출은 전체 심사를 거치지만, **TestFlight 내부 테스트(ASC 사용자 100명)는 심사 대상이 아니다.**
  스크린샷·설명·개인정보 처리방침 URL·App Privacy 질문지도 **내부 테스트에는 필요 없다.**
  실제 필수는 ① 앱 레코드 ② 서명 빌드 ③ **수출 규정 응답**(`ITSAppUsesNonExemptEncryption = false`) ④ 내부 테스터 그룹뿐이다.
  ⚠ 단 Apple 문서 간 충돌이 있어 하루 여유를 남긴다 → `16번 문서` R25
